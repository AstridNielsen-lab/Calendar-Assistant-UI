# AI Calendar Assistant

Bem-vindo ao **AI Calendar Assistant**, seu assistente de calendário inteligente alimentado pelo modelo **Google Gemini**. Este projeto combina tecnologia de ponta para gerenciar e organizar seus eventos de maneira eficiente e intuitiva.

---

## Funcionalidades

- **Assistente de Calendário com IA**: Um assistente virtual que auxilia no gerenciamento do seu calendário.
- **Login com Google**: Acesse e utilize o assistente fazendo login com sua conta Google.
- **Respostas Inteligentes**: Alimentado pelo modelo **Gemini**, fornecendo respostas contextuais e úteis.
- **Manutenção de Contexto**: O **Memory Buffer** permite que a conversa permaneça contextualizada para maior precisão e eficiência.

---

## Componentes do Fluxo de Trabalho

- **Chat Trigger**: Lida com as mensagens recebidas do usuário.
- **AI Agent**: Processa as solicitações enviadas pelos usuários.
- **Gemini Model**: Modelo de IA que fornece respostas inteligentes e precisas.
- **Memory Buffer**: Mantém o contexto das conversas para melhor experiência.
- **Google Calendar**: Integração direta para gerenciamento eficiente de eventos.

---

## Como Usar

1. Acesse o sistema e clique em **Sign in with Google**.
2. Autorize o acesso ao seu Google Calendar.
3. Use o assistente para criar, editar ou visualizar eventos do calendário de forma prática.
